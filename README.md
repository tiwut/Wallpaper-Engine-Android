# Wallpaper Engine Android

A lightweight, highly customizable live wallpaper engine for Android with a clean, polished UI and fluid animations. Easily manage your local image vault and define smart rules to change walls over time, battery levels, or via phone shake.

## Features

- **Dynamic Transitions:** Choose from over a dozen smooth visual transitions such as Crossfade, Wipes, Circular Reveals, Flips, Shrink-Grow, and more.
- **360-Degree Panorama Mode:** Create immersive live wallpapers out of any picture by mapping device movement to panning using the internal rotation vector sensor limitlessly.
- **Rules Engine:** Set up conditions like time schedules or device shake to shift to a specific image automatically.
- **Local Vault:** Fully offline and private gallery management — add images directly from your device storage, securely managed via Room DB.
- **Material 3 UI:** Engaging layouts, rich dynamic colors, and buttery Jetpack Compose screens.

## Quick Start
Clone the repository and build via Android Studio. Ensure you are developing for a supported minimum SDK, using the embedded Gradle wrapper.

```sh
git clone https://github.com/tiwut/wallpaper-engine.git
```
